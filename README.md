# TA Personal Timba

MVP WordPress para almacenar resultados históricos de loterías, inicialmente Quini 6.

## MVP 0.1.0
- Tablas propias y esquema documentado.
- Quini 6 precargado con cuatro modalidades de extracción.
- Alta manual.
- Eliminación irreversible con confirmación y log.
- Importación CSV con duplicados/conflictos.
- Vista pública responsive `[ta_personal_timba]`.
- Selector de lotería, modalidad, sorteo y cantidad.
- Vista Matriz dinámica según rango configurado.
- Frecuencia llamativa 4+ en los últimos 10 resultados seleccionados.
- Menú raíz extensible para futuros complementos.

Pozo Extra no se considera una extracción independiente.
